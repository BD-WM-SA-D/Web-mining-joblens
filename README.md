# Nhật ký làm việc – Web-mining-joblens

Nhánh này chứa nhật ký trong quá trình làm, tách khỏi nhánh chính để nhánh chính chỉ giữ mã, tài liệu và kết quả chính thức.

- `results.md`: nhật ký thí nghiệm, ghi theo thứ tự thời gian (đăng ký trước, kết quả từng lần chạy).
- `runs/`: kết quả từng lần chạy dạng JSON.
- `NHAT-KY.md`: các sự kiện và quyết định đáng nhớ.

Nhánh không chung lịch sử với `main`.
